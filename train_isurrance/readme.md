# 프로젝트명: 추석 KTX 티켓 발행관리 시스템

## 1. 프로젝트 개요 
  - 추석 KTX 열차 티켓 발행 관리하는 시스템 개발 프로젝트 
---
## 2. 개발환경
### 1)운영체제: Window 
### 2)개발언어: Python
### 3)DataBase: SQLite(sql)
### 4)DashBoard: streamlit 
---
## 3. Work Process
### 1)프로그램 요구사양 협의
- 프로그램 개발 주제 선정 회의진행
- 프로그램 개발에 필요한 요소들 논의하여 추출

### 2)프로그램 구조 설계
- 개체지향(OOP) Class Digram 설계
- 프로그램 흐름도(flow Chart) 작성
- DataBase 모델링
  
### 3)프로그램 로직 구현
- Class 로직 구현
- main 실행 로직 구현
