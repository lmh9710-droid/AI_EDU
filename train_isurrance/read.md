# 🚅 추석 KTX 티켓 발행 관리 시스템

> 추석 명절 기간 KTX 열차 티켓 발행 및 운행 노선을 효율적으로 관리하기 위한 Python 기반 대시보드 시스템 프로젝트입니다.

---

## 🛠️ 1. 개발 환경 (Tech Stack)

| 구분 | 기술 스택 |
| :--- | :--- |
| **Operating System** | Windows |
| **Language** | Python |
| **Database** | SQLite (SQL) |
| **Dashboard UI** | Streamlit |

---

## 🔄 2. Work Process

### 📌 2.1. 요구사양 협의
- **주제 선정**: KTX 티켓 발행 및 관리 시스템 개발 주제 확정
- **요소 도출**: 프로그램 개발에 필요한 핵심 기능 및 필요 요소 논의·추출

### 📐 2.2. 구조 설계
- **클래스 설계**: 객체지향(OOP) Class Diagram 설계
- **흐름도 작성**: 프로그램 핵심 로직 Flowchart 작성
- **DB 모델링**: SQLite 기반 데이터베이스 모델링

### 💻 2.3. 로직 구현
- **클래스 구현**: 비즈니스 로직 Class 모듈화
- **메인 로직**: Main 실행 구문 및 통합 프로세스 구축
