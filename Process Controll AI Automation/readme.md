**Bolt&Nut 공장 AI 자동화 공정관리 프로그램 개발 프로젝트** 

-----

**1. 추진 배경:**  
  - Bolt 및 Nut는 초당 수십개 생산이 되는   
    핵심 적인 뿌리산업 부품으로 육안검사 한계와  
    작업자 피로도 증가로 인한 불량위험  
   
  - AI를 활용한 설비 진동/ 전류 기반 예지보전을   
    자동화 할수 있는 차세대 공정관리 시스템 구축 필요

**2. 개발 목적**

  2-1. 비전 이상 탐지:  
  이상탐지(Anomaly Detection)모델을 활용하여   
  정상 데이터만으로 불량 검출  
    
  2-2. 설비 예지보전:   
  설비 센서 수집 및 LSTM 모델을 통한 설비 고장   
  이상 징후 사전 예측  
    
  2-3. 실시간 비동기 제어:  
  비전 이상 탐지 및 설비 예지보전 비동기 멀티스레딩  
  제어 구현 

**3. System Architecture**  

  3-1. thread1(비전 탐지 스레드)  
    1)카메라 프레임 수신   
    2)ONNX(Open Neural Network Exchange)   
       런타임 C++ 추론   
    3)불량 발생시 설비제어 스레드 배출   
      
  3-2. thread2(예지보전 스레드)  
    1)설비 센서  데이터 수신 C++ middleware   
    2) LSTM 모델 기반 설비 고장 추론  
    3)이상징후 발생시 긴급 정지/경고 명령 설비제어 스레드   
       배출   

  3-3. thread3(설비제어 스레드) 
    1)비전탐지 스레드 및 예지보전 스레드 명령 상시 수신  
    2)불량 감지 및 설비 이상시 제어신호 비동기 송신   

**4. 개발환경** 

  4-1. Language
    1)C++ 17(하드웨어 제어 및 추론)  
    2) Python(모델학습용)

  4-2. Library   
    1)Opencv 4.x(비전처리)  
    2)Pytorch(시계열 모델 학습)
    3)anomalib(이미지 모델 학습)
    4)ONNX(runtime C++ API)

**5. 단계별 추진 로드맵**

   5-1. 1단계(데이터 수집)
     1)양품 Bolt, Nut 이미지 1000장 데이터 확보  
     2)설비 센서 통신 검증   
  
   5-2. 2단계(모델 학습)  
     1)이상탐지(Anomaly Detection) 모델기반   
        이미지 데이터 학습  
     2)LSTM모델 기반 시계열 데이터 학습 알고리즘 구축  
  
   5-3. 3단계(추론 및 통합시스템 구축)  
     1)학습완료 모델 ONNX파일  변환 및 추론 시스템 구축  
     2)설비 제어 멀티스레드 시스템 구축   

   5-4. 4단계(현장실증 및 제어테스트)  
     1)구축된 시스템이 현장 요구사항 일치하는지 검증   
     2)제어시스템이 이상없이 제어되는지 검증
