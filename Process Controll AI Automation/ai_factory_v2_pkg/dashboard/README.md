# 예측 vs 실측 대시보드

## 설치 위치
```
~/ai_factory/
├── dashboard/
│   ├── server.py              서버 (Python 표준 라이브러리만 사용, DB 읽기 전용)
│   ├── index.html             화면
│   └── static/chart.umd.min.js  차트 라이브러리 (인터넷 없는 현장에서도 동작, MIT)
└── scripts/run_dashboard.sh   실행 스크립트
```

## 실행
```bash
cd ~/ai_factory && ./scripts/run_dashboard.sh
```
Windows 브라우저에서 `http://localhost:8050` 을 엽니다.

다른 PC에서 보려면 `SF_DASH_HOST=0.0.0.0` 으로 실행합니다. 이 경우 WSL 포트 포워딩과 방화벽 설정이 추가로 필요합니다.

## 화면 읽는 법
- **검은 굵은 선**: 실측 10초 평균. AI가 예측하는 대상과 같은 정의입니다.
- **파란 점선**: 5분 전에 낸 예측 P50. 예측한 시각이 아니라 **목표 시각에** 그립니다. 그래서 검은 선과 겹치는 정도가 곧 예측 정확도입니다.
- **파란 음영**: P10~P90 범위. 실측의 약 80%가 이 안에 들어오면 불확실성 추정이 맞는 것입니다.
- **빨간 실선**: 기준표 한계. **주황 점선**: 위험 경고(0.4).
- **세로선 오른쪽**: 아직 오지 않은 5분. 예측만 있습니다.
- **패널 아래 수치**: 목표 시각이 지난 예측을 실측과 대조한 평균 오차입니다. AI 값과, 현재값을 그대로 썼을 때의 값을 비교합니다. AI 쪽이 작아야 예측이 의미 있는 것입니다.
- **빨간 테두리 패널**: 최신 예측 P50이 기준표 한계를 넘은 항목입니다.
- **상단 띠**: 4호기 라인 상태입니다. 정지·퇴출 중이면 빨강, 경고등이 켜졌거나 허브 연결이 끊기면 주황입니다.

화면은 2초마다 갱신됩니다. 표시 기간은 10분, 30분, 1시간, 3시간 중에서 고를 수 있습니다.
